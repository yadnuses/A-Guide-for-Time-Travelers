# 年度初稿规范

本文件规定如何把已验收的年度资料包改写成面向公众的年度指南。撰稿人不需要任何额外背景，只需阅读：

1. 本文；
2. `research/YYYY/` 下各地区的 `facts.jsonl`、`opportunities.jsonl`、`summary.md`；
3. 必要时参考已有成稿的写法，例如 [`1900-1909/1901.md`](../1900-1909/1901.md)。

## 1. 交付物

每个年份一个文件，放在该年份所属的十年文件夹内：

```text
YYYY-YYYY/YYYY.md
```

十年文件夹覆盖连续的十个年份，例如 `1900-1909/`、`1910-1919/`。以 1911 年为例，路径是 `1910-1919/1911.md`。除目标年份外，不得修改其他年份的成稿或 `research/` 下的资料。

## 2. 固定结构

每篇按以下顺序组织，**不得拆成更多顶级栏目**：

```markdown
# YYYY：[适合该年的标题]

> **Demo v2｜第二人称故事化硬核指南**
>
> 引导语。

## 一、落地

## 二、世界棋盘

## 三、你的路线

## 四、随身工具

## 结语

## 附录：主要参考来源
```

资料、机会、风险和来源都应融入这四个板块、路线卡或附录，不另开章节。

## 3. 语气与叙事

采用第二人称「你」，但不写成空洞的游戏旁白：

- 开头用一个具体场景，把「你」放进当年主舞台。
- 写地点、声音、气味、价格和制度约束，不只写宏大事件。
- 主舞台有完整故事线；次重点和机会卡保持短而明确。
- 不写成功学口号。用具体选择、资本和风险推动路线。
- 不要把历史上的不平等包装成毫无代价的财富捷径。
- 幽默可以出现，但不能消解战争、灾难、殖民、歧视和劳工风险。

## 4. 核心设定

### 4.1 穿越条件

- 读者是带着现代知识和记忆穿越的「你」。
- 没有当地证件、现代设备或可靠的现代身份。
- 携带一笔可解释的小额启动资金，默认约等于当地普通劳动者 100 天工资。
- 启动资金不保证成功，只够启动第一笔风险投入。

### 4.2 年份时间线

每篇是独立时间线：从真实历史开局，可以写个人行动造成局部改变，但不要求一篇的改变影响另一篇。

### 4.3 历史预知

可以利用未来事件、技术、产业和历史人物，但必须写清：

- 当时是否能够接触；
- 是否有合法或实际的参与入口；
- 需要什么本金、身份、能力或关系；
- 何时退出；
- 失败时会发生什么。

公司后来成功不等于当时任意价格买股票都能赚钱，也不等于未上市企业当时能被普通穿越者买到。

## 5. 四个板块的写法

### 5.1 一、落地

写清楚：

- 你在哪里、什么时候、面对什么制度；
- 先要解决的身份、食宿、安全和现金问题；
- 主舞台的第一条可行行动；
- 不能用假证件、现代设备或不合理主角光环解决的问题。

不要把「空手」写成不现实的无敌生存。没有资料支持的地方，写成未核实的限制。

### 5.2 二、世界棋盘

只保留会影响行动的全球信息：

- 战争、革命、贸易、金融、法律、技术、灾害、流行文化；
- 主舞台以外的地区为何值得写；
- 哪些未来结果可能改变路线。

不写成编年史。事实必须来自资料包，无法核实的细节写入风险或不确定性。

### 5.3 三、你的路线

正文核心。每条路线使用统一路线卡：

```markdown
### 路线卡：标题

**阶段**：survival / first_capital / wealth_jump。

**当时入口**：具体做什么、找谁、从哪里开始。

**所需资本与能力**：现金、工具、身份、语言、技术、渠道、法律。

**收益与退出**：如何形成现金流或权益，何时转让、分红、回购或离开。

**风险与法律**：可能失败的方式、历史法律、现代法律差异、道德边界。

标签：`历史已验证` / `合理推演` / `私人股权与合伙` / `先知投资` / `当年合法今天未必`
```

主舞台路线应至少覆盖三个阶段：

1. **活下来**：食宿、身份、安全、短工或基本物资。
2. **第一桶金**：信息、服务、零售、供应、劳动、出版或低资本合伙。
3. **财富跃升**：私人股权、合伙、专利、产业整合、承销、媒体、基础设施或资源贸易。

次重点地区写短路线卡；机会卡只写一个明确入口和一条明确风险。

### 5.4 四、随身工具

放读者真正会用的信息：

- 年度行动日历；
- 语言速查；
- 避坑清单；
- 必要时加入工资、货币和物价速查。

语言只要求应急表达，不写成长篇语言课程。避坑清单必须覆盖身份、现金、法律、战争、灾害、合伙和现代法律差异。

## 6. 标签体系

标签贴在路线上，不单设顶级章节。

### 6.1 `历史已验证`

用于后来被真实历史结果证明的产业、企业、产品、组织或事件路线。必须：

- 有对应的 `history_proven` 机会记录；
- 后续结果来自真实事实；
- 说明结果与当前行动之间的差别；
- 不把历史公司的成功写成任何个人都能获得同样回报。

### 6.2 `合理推演`

用于资料支持一部分条件、但结果尚未被历史直接验证的路线。必须：

- `outcome` 与 `outcome_date` 为空；
- 清楚列出成立条件与失败条件；
- 不把可能性写成必然性。

### 6.3 `私人股权与合伙`

用于未上市公司、家族企业、合伙、承包、供货、承销、许可和产业服务：

- 明确资金、资源和劳动如何换成股权或现金流；
- 明确决策权、分红、回购、稀释和退出；
- 不虚构证券代码、股价、股息或交易所交易。

### 6.4 `先知投资`

用于提前认出后来成功的个人、企业、产业或制度窗口。必须写四件事：

1. 当时那个人或企业是谁、还在做什么；
2. 当时可进入的载体是什么；
3. 你提供了什么独特价值；
4. 退出和失败是什么。

### 6.5 `当年合法今天未必`

用于历史合法、灰色或后来受严格监管的行为：

- 解释当时法律和社会环境；
- 说明今天为何不同；
- 不写成现实行动建议；
- 不把欺诈、伪造、伤害、危险工业和强制劳动写成可行捷径。

## 7. 引用规则

- 正文使用连续数字编号：`[1]`、`[2]`、`[3]`。合并引用写作 `[3,4]`。
- 每个编号对应一条事实记录或一条已核验来源。
- 附录使用 `1. **事实ID** — 标题：URL` 的格式，编号与正文一一对应。
- 附录只列来源标题和 URL，**不显示访问日期**。
- 正文引用不能指向不存在的来源；`research/check_draft.py` 会检查编号连续性与附录条数。
- 重要事件尽量双源。来源冲突必须写进正文的边界或附录说明。
- **`facts.jsonl` 是事实依据，`opportunities.jsonl` 是路线依据。不得凭记忆添加事实。**

## 8. 投资路线要求

投资正文必须分两层：

### 8.1 事实层

- 企业、产品、产业、市场和制度的真实结果；
- 当时是否上市、能否入股、有无价格和交易渠道；
- 后来的结果日期和来源。

### 8.2 故事层

- 「你」如何用知识、能力、订单、合伙或服务换取进入资格；
- 如何获得现金流、股权、许可费或控制权；
- 如何承担稀释、失败、战争、政策和身份风险。

**禁止：**

- 编造公开股票价格；
- 编造股价涨跌、买卖日期和收益率；
- 把「后来成功」写成「任何投入都成功」；
- 把现代金融产品直接套用到旧制度；
- 把历史中的灰色或暴力机会写成现代推荐。

## 9. 资料缺口的处理

资料包 `summary.md` 中的缺口必须在成稿中诚实处理：

- 不删掉困难；
- 不用空泛常识替代缺失数据；
- 缺少价格时，写「按相近地区/年份参照」并说明近似；
- 缺少上市价格时，只写私人股权、合伙、服务或产业入口；
- 缺少法律原文时，只写已有事实能支持的法律风险；
- 来源冲突时，同时呈现两种口径并说明为什么不强行统一。

## 10. 写前检查

- [ ] 只使用本年度资料包和已确认的跨地区资料。
- [ ] 主舞台、次重点、机会卡与资料包覆盖范围一致。
- [ ] 四个顶级板块齐全，另有结语和附录。
- [ ] 路线卡包含五个固定字段。
- [ ] `history_proven` 路线有真实后续结果。
- [ ] `inferred` 路线不把结果写成事实。
- [ ] 私人股权、合伙、服务和承销的进入方式明确。
- [ ] 没有虚构股价、股息、证券代码或收益率。
- [ ] 所有事实都能追溯到 `facts.jsonl`。
- [ ] 正文引用连续，附录来源一一对应。
- [ ] 附录没有访问日期。
- [ ] 有语言速查和避坑清单。
- [ ] 有战争、灾难、身份、现金、法律和现代法律差异的边界提示。

## 11. 交付后检查

- [ ] Markdown 标题结构正确。
- [ ] 正文无悬空编号，附录无未引用编号。
- [ ] 无 `TBD`、`TODO`、占位符和虚构的「以后补」。
- [ ] 无编造的引用、价格、人物关系或历史结果。
- [ ] 不修改其他年份文件。
- [ ] 已运行 `python3 research/check_draft.py YYYY` 并通过。
