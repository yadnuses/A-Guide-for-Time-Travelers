## 五、版式与动效规范

- **安全区**：上下左右各留 8% 边距；主字幕居中偏上 1/3；落版文字靠左、二维码靠右。
- **字号（1080p 基准）**：主标 96–120px；金句 120–160px；中文副字 40–52px；**英文小字 28–34px（透明度 65–75%）**；落版地址 56–64px。
- **二维码**：180–220px，右侧居中，带 1–2px 浅色描边/圆角底板，下方小字「扫码进入 GitHub 仓库」。
- **颜色**：底色 `#0E1A2B`（深墨蓝）；主字 `#F5E6C8`（暖米金）；强调 `#E0A93B`（琥珀金）；风险/警示 `#C0392B`（暗红）；英文小字同主字降透明度。
- **动效语言**：以"字"为单位逐词浮现（stagger 60–120ms）；关键句用"马克笔横扫 / 手绘圈选"高亮；转场统一"纸片炸开 / 胶片闪白"。
- **节奏**：每句停留 ≥3.5s；S7 两行 slogan、S5 数字滚动严格跟 0:16 drop / 0:40 重音。

## 六、制作与质检

- **实现路径（推荐）**：HyperFrames 生成 kinetic typography，配乐作音轨，按上表时间码对齐，可确定性渲染 mp4；年代场景图可批量 AI 生成（统一做旧质感）。
- **发布前核对**：
  1. 开场 3 秒内出现「写给穿越者的致富指南，现已完全开源」；
  2. Slogan 完整出现在 S7（对应 drop 后的高潮）；
  3. 片尾出现「欢迎加入……开源共建团队」+ 完整仓库地址 + 二维码，地址停留 ≥4s；
  4. 每句主字幕英文小字清晰但不喧宾夺主；
  5. 历史表述沿用"事实 / 推演"口径，不写成投资建议；
  6. ⚠️ 配乐公开发布前确认版权；⚠️ 仓库当前为空仓，发布前先把内容与 README 推上去。
