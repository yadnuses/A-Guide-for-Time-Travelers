# 给穿越者的指南

一部按年份编写的"穿越指南"：如果你带着现代记忆回到某一年，落地当天会遇到什么、钱值多少、法律怎么管你、哪些生意在当时合法且真能做成。

每一年的内容由两层构成：**资料层**把可核验的事实、法律条文、物价、工资与商业机会逐条落成带原文摘录的记录；**成稿层**把这些记录写成第二人称的年度指南，给出生存、第一桶金、财富跃升三个阶段的具体路线卡，并写明每条路线的资本门槛、退出方式与法律风险。

## 现在有什么

| 层 | 覆盖范围 | 规模 | 状态 |
|:---|:---|:---|:---|
| 年度初稿 `03_年度初稿/` | 1900—1910 | 11 篇 | 已审校，可读 |
| 资料库 `02_资料与考据/` | 1900—1930 | 172 个地区包、1,791 条事实、521 条机会 | 全部通过机器校验 |
| 地域规划 `01_设计与规划/` | 1900—2025 | 126 年的主舞台与次重点 | 规划完成 |

**请注意这个落差**：资料已经备到 1930 年，但成稿只发布到 1910 年。1911 年之后的初稿尚未经过审校，因此不在本仓库中。仓库里出现的每一年成稿，都对应 `04_审校与修订/` 下的一份审校记录。

## 数据怎么组织

每个「年份 / 地区」是一个资料包，三个文件：

```
02_资料与考据/1910/US/
├── facts.jsonl          事实记录，每条带 URL、原文摘录、核验状态
├── opportunities.jsonl  机会记录，标注是「历史已验证」还是「合理推演」
└── summary.md           该包的发现、冲突、缺口与写作建议
```

事实记录的核验状态分三档：`cross_checked`（多源交叉）、`single_source`（单一来源）、`conflicted`（来源互相矛盾，两种口径并列保留，不强行统一）。矛盾不消除，是这套资料的设计原则之一——读者能看见证据本身的分歧。

## 怎么校验

仓库自带脚本，均可从任意目录运行：

```bash
# 校验资料包结构与字段完整性（无参数则全库）
python3 02_资料与考据/validate_pack.py

# 校验年度初稿：六栏目结构、路线卡五字段、引用连续、附录对应（无参数则扫描全部）
python3 02_资料与考据/check_draft.py

# 年度汇总：各年事实数、机会数、五类核心覆盖
python3 02_资料与考据/summarize_year.py 1900 1910

# 列出引用了维基镜像站/代理站的记录，供替换为一手来源
python3 02_资料与考据/list_mirror_sources.py
```

## 这套东西的前提

以下是写作时自我约束的规则，也是阅读时该带着的怀疑：

- **不虚构价格。** 没有可核验的股票价格、股息、收益率、证券代码，就只写私人股权、合伙、承包、服务入口。
- **不把"后来成功"写成"任何投入都成功"。** 一家公司后来成为巨头，不等于当年任何人买它的股票都能赚钱，也不等于未上市企业当年能被普通穿越者买到。
- **不美化暴力与不义。** 殖民暴力、种族屠杀、政治清洗、法西斯上台，按史实与数字记录，不猎奇、不煽情、不替代读者判断。
- **缺口如实标注。** 资料包里没有的数据，成稿里就写"未取得"，不用常识填补。

## 已知局限

- **来源质量不均。** 全库约 17.4% 的记录引用的是维基镜像站或代理站而非一手档案，集中在 1929—1930 年（这两年的可获取一手材料较少）。`list_mirror_sources.py` 可输出逐条清单。
- **年份覆盖不均。** 1900—1910 已审校；1911—1930 只有资料，没有成稿；1931—2025 只有规划。
- **地区深度不均。** 每年一个主舞台承载完整故事线，次重点地区篇幅明显更短，机会卡只给一个入口和一条风险。
