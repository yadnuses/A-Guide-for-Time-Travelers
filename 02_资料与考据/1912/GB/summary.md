# 1912×GB 资料摘要

## 任务范围
覆盖英国（主舞台：贝尔法斯特，涉伦敦、纽约的关联节点）1912年全年，重点为泰坦尼克号从建造、下水、处女航到沉没及英美两场调查。已搜集类别：events（6条）、technology_industry（2条）、law_identity（2条）、survival_cost（2条）、finance（2条）、business_career（2条），共16条。safety_medical 未单列，工伤与医疗条件并入 BIZ-001；language 未单列。

## 核心发现
- 1912-GB-EVENT-001/002：龙骨1909年3月31日铺设、1911年5月31日下水、1912年4月初试航——贝尔法斯特的建造周期约26个月，是主舞台可行动窗口的起点。
- 1912-GB-EVENT-003/004：4月10日启航、载2208人；4月14日23:40撞冰、15日02:20沉没，1500余人死亡。
- 1912-GB-TECH-001 + LAW-001：20艘救生艇容量1178人，却已“超过”贸易委员会法定定额——法定标准按吨位而非人数，制度缺陷与工程缺陷叠加。
- 1912-GB-EVENT-005/006：英国调查5月2日—7月3日（默西勋爵，96名证人、25622问）；美国参议院听证4月18/19/22日、5月28日提交报告（史密斯参议员）。两场调查同期并行，构成1912年春夏的跨国舆论场。
- 1912-GB-FIN-001/002：船体与机械各保100万英镑、保费7500英镑（每百英镑15先令），30天内全额赔付；4月15日再保险费率60%→25%以下的剧烈摆动，是当时伦敦海运保险市场的信息反应样本。
- 1912-GB-COST-001 + BIZ-001/002：近1.5万工人、周工资总额约2.5万英镑、60小时工作周、建造期254起事故8人死亡——工资、工时与工伤构成本包生存成本与职业风险的三角。

## 主要机会
- 1912-GB-OPP-001（inferred / survival）：船厂班次食宿与周薪结算的小额食宿生意。
- 1912-GB-OPP-002（inferred / first_capital）：工伤与疾病给付的文书代办与互助会代理。
- 1912-GB-OPP-003（inferred / first_capital）：救生设备改装与船员操练合规服务。
- 1912-GB-OPP-004（inferred / first_capital）：海难特稿、图片与证词经纪。
- 1912-GB-OPP-005（inferred / wealth_jump）：船舶无线电报值守、检修与操作员培训。

## 后来者的成功，当下的财富
本包未形成证据充分的 `history_proven` 路线。原因有二：其一，泰坦尼克号本身是失败案例，不能作为“后来成功”的标的；其二，本包内可核验的后续结果（如救生艇国际规则、无线电报强制值守）发生在1914年及以后，缺少本包内可引用的结果事实，按规范不得把推演写成已验证结果。因此 OPP-003、OPP-005 均标为 `inferred`，并在 `uncertainties` 中注明立法节奏与资质门槛未核实。若年度初稿需要一条英国侧“后来者”路线，应改引 1912-CN-OPP-001（中国银行）或 1912-US-OPP-001（无线电立法），不要在英国包内虚构后续收益。

## 来源冲突
- 救援人数：Britannica 与 Titanic Inquiry Project 均作705人，另有中文报道作710人；本包采用705，并在 EVENT-004 引用 Britannica 作为交叉来源。
- 美国听证起始日：senate.gov 官方列表记“Hearings: April 18, 19, 22, 1912”，部分二手叙述称“4月19日开始”；本包以参议院官方列表为准，EVENT-006 已注明三个开庭日。
- 船厂工资口径：The Irish Times 同一篇报道称“平均日薪2英镑”，而同篇又记“近1.5万人、周工资总额约2.5万英镑”，两者相差约7倍，日薪说与工资总额无法相容；本包 COST-001 只采用可互相校验的“人数+周工资总额+60小时工作周”，不使用“日薪2英镑”，并在本条标 `cross_checked`/`medium`。
- 三等舱死亡数：Britannica 记“约710人中约174人生还”，与常引的“706名乘客、528人遇难”略有差异，属统计口径差异，未强行统一。

## 资料缺口
- 贝尔法斯特1912年的面包、煤炭、房租、电车票价无一手数据；COST-001 只能给出工资与工时，无法折算实际生活成本，故 OPP-001 的毛利无法测算。
- 英国贸易委员会救生艇定额的法规原文（吨位分级表）未取得，LAW-001 依据 Britannica 的转述。
- 英国调查最终报告（1912年7月30日公布）的建议条文未逐条核对，OPP-003 的合规服务内容属方向性推演。
- 马可尼公司1912年的股价、股息与上市状态未核实；Marconi 丑闻（1912年夏）因缺少可引用的价格与交易细节，本包未单列事实。
- 哈兰德与沃夫夫船厂1912年的工伤赔偿实际支付标准、工会准入规则未取得。
- safety_medical 类别未单列：贝尔法斯特的医院、结核病与婴儿死亡率无可靠来源。

## 主舞台建议
适合作为年度主舞台。理由：单一城市（贝尔法斯特）同时承载造船工业、工会与工伤、航运保险、跨大西洋无线电报与两场跨国调查，行动窗口从1月投保、4月沉没到5—7月庭审层层推进；工资与工时数据可支撑生存线，救生设备与电报值守可支撑第一条上升线。建议主故事线锚定4月10日—7月3日，落地点选船厂东侧街区，避免把沉没写成猎奇或投机题材。
