# 1919×IT 资料摘要

## 任务范围

覆盖意大利王国，重点为罗马（和会外交与议会政治）、阜姆（1919年9月占领事件）与米兰、都灵（法西斯战斗团成立、红色二年与菲亚特量产）。时间范围为1919年全年，必要处延伸至1920—1926年以记录后续结果。数据类别覆盖 `events`、`survival_cost`、`law_identity`、`finance`、`technology_industry` 五类核心，共10条事实；另含 `business_career` 与 `safety_medical` 的空白说明（见“资料缺口”）。机会3条。

## 核心发现

- `1919-IT-EVENT-001`：巴黎和会确认意大利取得南蒂罗尔、特伦蒂诺、伊斯特里亚、的里雅斯特与扎拉，但阜姆与达尔马提亚未归意大利。奥兰多4月24日退出和会、5月初返回、6月23日辞职。民族主义舆论由此形成“残缺的胜利”叙事，这是理解本年意大利政治激化的起点。
- `1919-IT-EVENT-002`：9月12日邓南遮率约186名志愿兵自龙基进入阜姆，数日内扩至约2500—2600人，迫使美英法占领军撤出并宣布并入意大利。意大利政府反向封锁阜姆，形成“本国政府封锁本国民族主义者占领的城市”的奇特局面。
- `1919-IT-EVENT-003`：3月23日法西斯战斗团在米兰圣墓广场成立，早期纲领含共和、男女普选、八小时工作制与对资本重税。该组织在同年11月大选中得票不足5000张、零席位——1919年的法西斯仍是边缘团体，这一反差是本包最重要的判断。
- `1919-IT-EVENT-004`：11月16日首次比例代表制大选，社会党156席（32.28%）、人民党100席（20.53%），自由派失去多数。旧执政联盟瓦解，但左翼与天主教党并未联合执政。
- `1919-IT-EVENT-005`：红色二年（1919—1920）的都灵、米兰工厂委员会与工厂占领，波河平原农业罢工与占地；约500万军人复员。
- `1919-IT-COST-001`／`COST-002`：1919年4月43城零售食品价格较1914年7月高181.2%，罗马6月食品价高125%；米兰工人家庭12月每周食品支出中肉类15.60里拉、面包7.96里拉。物价与工资的剪刀差是罢工与占领运动的直接经济背景。
- `1919-IT-LAW-001`：8月15日选举法以比例代表制取代单名多数制，选民增至约1100万，前线服役者不受年龄限制，女性仍无选举权。
- `1919-IT-FIN-001`：里拉对美元由6月8.05跌至12月13.07，对英镑由37.33跌至50.08；1919年批发物价指数450、生活成本指数268（1913=100）。
- `1919-IT-TECH-001`：11月菲亚特推出501型，上市价约32000里拉，林格托工厂总装，至1926年累计约4.6万辆，是意大利第一款大批量生产的汽车。

## 主要机会

- `1919-IT-OPP-001`｜`history_proven`｜`wealth_jump`｜菲亚特501型量产车的经销、车身配套与私人股权参与。历史结果：501型至1926年约4.6万辆，菲亚特1925—1929年占全国产量约72%。
- `1919-IT-OPP-002`｜`inferred`｜`first_capital`｜阜姆占领区封锁缝隙下的粮食、燃料与印刷品供应。高周转、高政治风险，法律状态在当时即为非法。
- `1919-IT-OPP-003`｜`inferred`｜`first_capital`｜军工订单收缩后的二手机床与汽车零部件配套。启动门槛低于整车，但受1921年银行业危机威胁。

## 后来者的成功，当下的财富

`1919-IT-OPP-001` 是唯一一条 `history_proven` 路线。后续真实结果为：501型自1919年11月投产，至1926年累计约4.6万辆；菲亚特在1925—1929年生产19万辆汽车，相当于意大利全国产量的72%，林格托成为欧洲首个按大批量生产设计的整车厂。当时的参与渠道限于区域经销、车身与灯具配套、以及受让家族或私人股东股份——菲亚特当时是私人股份公司，未找到1919年的对外招股文件或交易所报价，**不得假设可以在交易所买入其股票**。执行限制包括：里拉一年内对美元贬值约六成，进口钢材与机床成本急升；1920—1921年军转民需求波动与银行危机；工人占领工厂导致交付中断。历史成功不等于任意时点进入都能获利，也不等于当时存在可流通的股权凭证。

## 来源冲突

1. **阜姆占领兵力**：英文条目记“186名军团志愿兵”出发、数日内增至约2500人；中文条目记“约2600人”。本包合并表述为“先遣约186人，数日内增至约2500—2600人”，标 `cross_checked`。
2. **林格托工厂建成时间**：都灵大学论文记“1919年建立”，另有汽车史材料记1923年竣工。本包只采用“1919年总装501型”的可核验部分，未在事实中断言厂区全部建成年份，并列入资料缺口。
3. **里拉汇率的口径**：Einaudi 引用的《经济学人》表为半年末牌价，1914-1918-online 为年平均价（1919年对美元13.1、对英镑50.1）。两者数值接近但口径不同，本包在事实中并列月份数据与年度指数，未混用。
4. **法西斯战斗团成立人数**：来源记“50至200名支持者”，区间本身来自同一来源，未作进一步精确化。

## 资料缺口

- **面包等具体商品的里拉单价**未取得。现有材料只有指数（181.2%、125%）与家庭周支出结构，缺少“每公斤面包多少里拉”的直接报价，无法换算绝对生存成本。
- **1919年意大利房租与燃料的绝对值**缺失；仅知米兰房租因战时冻结立法几乎未涨（占总支出4.30%），这一条对判断居住策略很关键，但缺原始租金水平。
- **复员军人的具体安置政策与退伍金标准**未核实。`EVENT-005` 中“约500万复员”来自教学材料，属单一来源，已标 `single_source`／`medium`。
- **菲亚特501型的经销商分成、车身配套加工费、实际利润率**均未取得；`OPP-001` 的收益路径只能定性描述。
- **阜姆城内的物价、封锁执行力度、占领政权债券的偿付结果**未核实；`OPP-002` 因此只能给 `low`。
- **`business_career` 与 `safety_medical` 两类核心之外的数据未单独建条**：本包未找到1919年意大利职业介绍许可、工伤统计或传染病死亡率的可靠一手材料。红色二年的伤亡与警力数据亦缺。已用 `EVENT-005` 与 `COST-001` 部分覆盖其经济社会背景，但没有独立条目，故在这两类上应视为未完成。
- **1919年意大利女性劳动参与与妇女组织的具体活动**未搜集，仅知女性未获选举权。

## 主舞台建议

适合作为**次重点**，不宜单独承担年度主舞台。

理由：本年的意大利同时具备三条强叙事线——和会外交的挫败（“残缺的胜利”）、阜姆的准国家实验、法西斯战斗团与红色二年的街头对撞——且三者集中在同一年的同一个亚得里亚海方向，戏剧张力极高。物价指数、里拉汇率、菲亚特量产与选举法改革又提供了可核算的经济与制度底盘，穿越者可以同时在“外交翻译”“军工转民用”“占领区补给”三条线上行动。

但作为主舞台有三个硬伤。其一，1919年的法西斯在选举中几乎不存在（米兰不足5000票、零席位），若以“法西斯上台”为故事预期，会与本年事实严重脱节；真正的主角是社会党、人民党与退伍军人团体。其二，阜姆事件的法律状态在当年即为非法，主线若放在阜姆，主角必须长期处于被意大利政府封锁与查缉的位置，行动空间受挤压。其三，缺少面包单价、房租与工资的绝对值，生存成本只能写相对指数，写实感弱于 FR 与 DE。

因此建议：以罗马—巴黎为政治线、以都灵—米兰为产业线，阜姆作为一条高风险支线或对手戏，而不作为主舞台中心。
