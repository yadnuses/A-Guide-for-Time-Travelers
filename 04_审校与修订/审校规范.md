# 年度初稿审校规范

本文件定义 `03_年度初稿/` 各篇的审校流程、判据和记录格式。审校者只需阅读本文、`年度初稿撰写规范.md`、目标年份的初稿及其 `02_资料与考据/YEAR/` 资料包，不需要上一轮会话记忆。

## 1. 三层校验

审校不是一次通读，而是三层，前一层的结论是后一层的输入。

| 层 | 查什么 | 方式 | 产出 |
|:---|:---|:---|:---|
| **L1 机器层** | 结构、引用闭环、来源 ID、占位符、附录访问日期 | `check_drafts.py` 自动跑 | `machine_check.json` |
| **L1b 跨年层** | 是否引用非本年度的资料包事实 | `check_cross_year.py` | 控制台清单，逐条登记 |
| **L2 事实层** | 每条引用是否真的支撑对应论述；数字、日期、法律条款是否与 `facts.jsonl` 一致；有无编造 | 逐条比对资料包 | 审校记录的「事实核对」节 |
| **L3 叙事层** | 设计文档第 7 节的九项质量验收 | 通读全文 | 审校记录的「叙事审校」节 |

L1 未通过不得进入 L2。L2 发现编造必须回到 L1 重新核引用。

### 1.1 关于跨年引用

规范要求每篇只使用本年度资料包。实际写作中，若某年资料包缺少某一类数据（如 1901 年缺生存成本），可借用相邻年份的事实作为物价锚点，但必须同时满足：

1. 正文显式标注该数据的年份，并说明"不是本年数字"；
2. 附录如实列出该条来源及其年份；
3. 审校记录「事实核对」节标注"跨年度"，并在「未解决问题」里登记为 P2 待补。

三项缺一，即按 P0 处理。

### 1.2 引用写法

正文只允许逐个编号或逗号合并，如 `[1]`、`[14,15]`。**不允许区间写法 `[12-15]`**，机器层会告警，须展开为逐个编号。

## 2. 严重级别

| 级别 | 定义 | 处理 |
|:---|:---|:---|
| **P0 阻断** | 违反规范硬条款：结构错、引用悬空或未闭环、附录来源重复、编造事实或价格、出现占位符、访问日期残留 | 必须当轮修完，否则不得标记通过 |
| **P1 重要** | 事实与资料包不一致、时代错置、法律标签错误、物价明显偏离当年水平、路线无法启动 | 当轮修完；无法核实则降级为 P2 并写明原因 |
| **P2 记录** | 表述可优化、篇幅失衡、叙事节奏、资料缺口提示不足 | 记入审校记录，不擅自改写 |

## 3. 修改权限边界

审校者可以改的：

- 结构与标题，使其符合四板块 + 结语 + 附录。
- 引用编号的补、删、重排，以及附录条目的增删（依据只能是 `facts.jsonl` / `opportunities.jsonl`）。
- 与资料包矛盾的具体数字、日期、人名、法条。
- 路线卡缺失的固定字段。
- 明显的笔误、错字、错误的量词与货币单位。

审校者不可以做的：

- **不得凭记忆新增事实。** 需要新事实时，只能引用已存在的 `facts.jsonl` 记录；资料包里没有的，写进「资料缺口」，不得写入正文。
- **不得虚构股价、股息、收益率、证券代码。**
- **不得把 `inferred` 机会写成已实现的结果**，也不得给 `history_proven` 机会添加资料包中没有的后续数字。
- **不得改动 `02_资料与考据/` 下的任何文件**（资料问题只能记录）。
- **不得跨年份修改**，除 `工作日志.md` 与 `整理报告` 由主线程统一维护。
- 大段改写（超过一段）只在 P0/P1 成立时进行，且改后须重新跑 L1。

## 4. 内容验收九项判据

对应设计文档第 7 节。每项给出可判定的失败特征。

1. **年份与日期自洽**：正文出现的事件日期与 `facts.jsonl` 的 `date` 一致；同一年内事件先后顺序不倒置；"当年"指代不跨越年份边界。失败特征：正文写"3 月"而事实为 4 月；把次年在发生的事写成今年。
2. **货币与物价合理**：工资、房租、食品、交通价格与当年当地水平同量级；货币单位与年份匹配（如 1900 年德国用马克、法国用法郎、美国用美元）；不做跨币种无依据换算。失败特征：面包价与月薪比例失真；把欧元、人民币套用到 1900 年。
3. **无时代错置**：技术、制度、物品、术语不早于该年出现。失败特征：1930 年出现喷气机；1900 年出现"GDP"这类后世统计概念且未说明。
4. **生存路线可启动**：主舞台的 `survival` 级路线在"无证件、无本地关系、仅有启动金"条件下有第一步可执行动作，且不依赖主角光环。失败特征：直接获得本地大亨信任；凭空拿到营业许可。
5. **财富跃升有依据**：`wealth_jump` 级路线写明载体、进入资格、资本来源和退出方式，不是"抓住风口"式空话。
6. **科普准确且贴合**：技术原理、金融机制、医学知识的陈述正确，且出现在角色需要它的位置，不是百科插页。
7. **法律标签正确**：`当年合法今天未必` 类路线同时给出当时法律状态与现代差异；不把欺诈、伪造、强制劳动写成捷径。
8. **事实可追溯**：正文每条 `[n]` 都能在附录找到，附录每条都能在 `facts.jsonl` 找到，`fact` 字段确实支撑该处论述。
9. **篇幅与主次相符**：主舞台明显长于次重点，机会卡最简；语言速查保持简短（不超过 30 行）；避坑清单覆盖身份、现金、法律、战争、灾害、合伙、现代法律差异七类。

## 5. 审校记录格式

每篇一份，路径 `04_审校与修订/YEAR-审校记录.md`。

```markdown
# YEAR 审校记录

- 审校日期：YYYY-MM-DD
- 初稿字数（字符）：
- L1 机器校验：通过 / 不通过（列出残余问题）
- 结论：通过 / 有条件通过 / 退回

## 一、已修复

| 编号 | 级别 | 问题 | 处理 |
|:---|:---|:---|:---|

## 二、事实核对（L2）

| 引用 | 正文论述摘要 | 事实 ID | 是否支撑 | 说明 |
|:---|:---|:---|:---|:---|

只列抽查项与全部可疑项，不必罗列全部引用。

## 三、叙事审校（L3）

按九项逐条给结论：通过 / 不通过 + 依据。

## 四、未解决问题

| 编号 | 级别 | 问题 | 建议 |
|:---|:---|:---|:---|

## 五、资料缺口

列出该年正文回避或降级处理的内容，以及补什么资料可以解除限制。
```

## 6. 通过标准

同时满足以下全部条件，才可在审校记录写「通过」，并由主线程迁入 `05_定稿待迁移/`：

- [ ] `check_drafts.py` 对该篇输出 `OK`。
- [ ] 无 P0、无未处理的 P1。
- [ ] 九项内容验收全部通过，或有明确降级理由。
- [ ] 附录每条来源都能在资料库解析到 ID。
- [ ] 审校记录五节齐全，未解决问题已登记。

## 7. 执行顺序

1. 主线程跑 `check_drafts.py`，得到全库 L1 结果。
2. 按年份分派审校，每篇独立，互不改写对方文件。
3. 审校者完成 L1 修正 → L2 抽查 → L3 通读 → 写记录。
4. 主线程复跑 `check_drafts.py` 复核，抽查审校记录的事实核对节。
5. 全部通过后更新 `工作日志.md` 与 `整理报告`，迁移定稿。
